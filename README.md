# Rollercoaster Billing System – Python

A beginner-friendly Python script that calculates the total cost of a rollercoaster ride. The program checks the user's height to determine eligibility, applies different prices based on age, and adds an optional photo fee. It's a simple project demonstrating user input and conditional logic.

## Features
- Height check for ride eligibility
- Age-based ticket pricing
- Optional ride photo add-on
- Automatic bill calculation
